# Hokii 錢掌櫃 MVP

Pengwin 企鵝隊競賽原型。上傳請款文件或貼上文字，核對收款資訊，試算付款後30天資金，留下人工覆核紀錄。

## 立即展示

Windows：雙擊「啟動MVP.cmd」，在詢問API時按Enter即可，接著開啟 http://127.0.0.1:8787 。終端機視窗要保持開啟。

也能直接用瀏覽器開啟 dist/index.html，或交付的「Hokii錢掌櫃_離線展示.html」。六個情境、規則核對、現金流與匯出功能可離線展示；真實AI辨識要透過本機伺服器。

## 啟用真實OpenAI辨識

重新啟動「啟動MVP.cmd」，選y並輸入自己的OpenAI API key。輸入不顯示，金鑰只保存在伺服器程序的環境變數，不寫入檔案、不傳送到網頁。預設模型gpt-5-mini，可用OPENAI_MODEL環境變數更換帳戶可用的模型。

辨識支援PDF、PNG、JPG、WebP與貼上文字，單一文件8MB。文件會傳往OpenAI，請先使用合成或經授權且處理過敏感欄位的資料。回傳結果一定要人工確認帳號、金額、日期等關鍵欄位。

OpenAI API會產生費用；此套件不含金鑰或額度。請先在API帳戶確認額度。伺服器使用store:false，這不等於零資料留存。

## 3分鐘展示順序

1. 點「正常付款」：看綠燈及原文依據。
2. 點「可疑帳號變更」：看新帳號與催促話術；系統要求用原先保存的電話查證。
3. 點「薪資缺口」：看付款後的最低餘額、缺口日期及金額。
4. 點「資料不足」：薪資或餘額未知時顯示灰燈，不把未知當零。
5. 回到正常案例，填覆核姓名並完成紀錄，再修改付款帳號，展示核准失效。
6. 匯出付款核對單，說明所有計算與異常條件可追溯。

## 可做與待合作功能

內建情境全部是合成示範。系統只核對使用者提供的文件與紀錄；沒有銀行戶名、警示帳戶或灰名單查詢權限，也不會實際匯款。綠燈表示已完成的檢查未見異常，不代表帳號經銀行驗證或保證無詐騙。

現金流以輸入的可用餘額與預定收付款試算；預期應收款另提供延遲情境。單次付款避免重複扣除。資料缺漏、過期或日期不正確都要補齊後重新核對。

覆核紀錄及供應商資料只供這部瀏覽器的競賽展示使用，未實作正式多使用者身分認證。核准僅適用工作台中的付款版本，无法控制使用者在另一個網銀視窗修改交易。未與臺灣企銀正式合作或接入其系統。

發現資金不足時可產生需求摘要並前往臺灣企銀微企享e貸官網；核貸與撥款仍由銀行處理，尚未到帳的貸款不計入可用資金。

## 開發與測試

需要Node.js 22以上，沒有額外套件安裝：

```text
node server.mjs
node --test tests/*.test.mjs
```

前端位於dist，規則引擎是dist/engine.js。數字運算與燈號由程式完成；AI只擷取文件與引用原文，未啟用時不假裝使用了AI。測試使用合成資料與模擬API回應，不會消耗真實API額度。
